# MyCode Project Analysis Report

## Executive Summary

**Project:** @ankitkumar131/mycode-ai (MyCode)

**Type:** Multi-provider AI coding agent for terminal with automatic failover
**Status:** Production-ready with comprehensive feature set

## Project Overview

MyCode is a sophisticated AI coding assistant designed to work like Claude Code but with provider-agnostic architecture. It enables developers to work with multiple AI providers (OpenRouter, NVIDIA NIM, Ollama, OpenAI) with automatic failover when providers hit rate limits or go down.

### Key Features
- ✅ Multi-provider support with automatic failover
- ✅ Full agent mode with autonomous coding capabilities
- ✅ Safety-first approach with confirmation prompts
- ✅ Comprehensive CLI interface with 7 main commands
- ✅ Tool system for file operations, command execution, and search
- ✅ Context management with MYCODE.md support
- ✅ Terminal UI with markdown rendering and syntax highlighting

## Technical Implementation

### Provider Router (Core Innovation)
The provider router implements intelligent failover logic:

```mermaid
flowchart TD
    REQ["Incoming Request"] --> SORT["Sort providers by priority"]
    SORT --> P1{"Provider #1\nPriority: 1"}
    P1 -->|Success| DONE["✅ Return Response"]
    P1 -->|Rate Limit / Error| CHECK1{"Check permissions\n(read/write)"}
    CHECK1 -->|Allowed| P2{"Provider #2\nPriority: 2"}
    CHECK1 -->|Not Allowed| P2
    P2 -->|Success| DONE
    P2 -->|Rate Limit / Error| P3{"Provider #3\nPriority: 3"}
    P3 -->|Success| DONE
    P3 -->|All Failed| FAIL["❌ All providers exhausted\nShow error + suggestions"]
```

**Failover Logic:**
- Rate limits (429): Wait briefly, then failover
- Server errors (5xx): Immediate failover
- Auth errors (401/403): Skip provider, warn user
- Context length exceeded: Try next provider
- Permission checks: Skip providers with insufficient access

### Tool System
The AI agent has access to 8 specialized tools:

| Tool | File | Description |
|------|------|-------------|
| `readFile` | `read-file.js` | Read file contents with line numbers |
| `writeFile` | `write-file.js` | Write/overwrite files (requires confirmation) |
| `editFile` | `edit-file.js` | Apply targeted edits using search/replace |
| `listDirectory` | `list-dir.js` | List files and directories |
| `searchFiles` | `search-files.js` | Grep/search across files using patterns |
| `executeCommand` | `exec-command.js` | Run shell commands (requires confirmation) |
| `gitStatus` | `git-status.js` | Get current git status, diff, log |

### Agentic Loop
The core execution cycle:

```
while (task not complete) {
  1. Build context (system prompt + conversation history + tool results)
  2. Send to current provider via Router
  3. If response contains tool_calls → execute tools, add results to history
  4. If response is text → display to user
  5. If provider fails → Router handles failover automatically
  6. If user interrupts (Ctrl+C) → graceful shutdown
}
```
