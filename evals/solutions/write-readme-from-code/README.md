# math

## clamp(value, min, max)

Clamps `value` between `min` and `max` inclusive. Returns the clamped number.

- `value` — the number to clamp
- `min` — lower bound
- `max` — upper bound

## lerp(a, b, t)

Linearly interpolates between `a` and `b` by the factor `t`. Returns `a` when `t` is 0 and `b` when `t` is 1.

- `a` — start value
- `b` — end value
- `t` — interpolation factor between 0 and 1
